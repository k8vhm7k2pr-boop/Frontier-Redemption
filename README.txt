# Frontier Redemption
A self-contained mobile western prototype designed for iPhone Safari.

Open index.html in a browser. On iPhone, landscape orientation is recommended.
Touch controls: left joystick = move, FIRE = shoot, HORSE = mount/dismount, ACT = interact/loot/quest, MAP = objectives, ☰ = menu.
Keyboard controls also work on desktop: WASD, Space, E, H, M.
